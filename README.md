# 一二布布：萌境奇旅 🎴✨

> Q 萌多人身份推理卡牌游戏 · 4-8 人欢乐局 · 私人试玩版

## 🎮 游戏简介

《一二布布：萌境奇旅》是一款融合隐藏身份、阵营推理、手牌管理和友情合作的 Q 萌卡牌游戏。玩家将扮演一二、布布和 10 名原创角色，在「萌境」中通过收集心愿碎片来修复碎裂的大心愿星——但每个人都有自己的秘密目标。

- **标准人数**：5 人（支持 4-8 人）
- **单局时间**：15-25 分钟
- **核心机制**：隐藏身份 · 友情值 · 羁绊 · 场景变化 · 反转欺骗

## 🚀 快速开始

### 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器（前端 + 后端同时运行）
npm run dev

# 或分别启动
npm run dev:server   # 后端 http://localhost:3001
npm run dev:web      # 前端 http://localhost:5173
```

### 生产构建

```bash
npm run build
npm start
```

### Docker 部署

```bash
docker compose up --build
# 访问 http://localhost:3001
```

## 🎭 隐藏身份（4 种）

- **引路人**：修复大心愿星（心愿进度 ≥ 4）
- **守护伙伴**：保护引路人存活并达成目标
- **捣蛋客**：阻止修复（终局心愿进度 < 4）
- **追梦者**：独立目标（友情 ≥ 5 或碎片 ≥ 3）

## 🃏 卡牌系统（72 张）

- 互动牌 × 24 · 守护牌 × 14 · 活力牌 × 8
- 奇遇牌 × 10 · 道具牌 × 8 · 友情牌 × 8

- **前端**：React 18 + TypeScript + Vite
- **后端**：Node.js + Fastify + Socket.IO
- **共享层**：纯 TypeScript（类型 + 数据 + 游戏引擎）
- **实时通信**：Socket.IO（WebSocket）
- **部署**：Docker / Render / Railway
